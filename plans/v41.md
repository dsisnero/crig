# v0.41.0 Porting Plan

**Upstream release:** `v0.41.0` (commit `68b4eabb8c9cf749ca73c917b9306e97fb0eda24`)
**Previous baseline:** `v0.40.0` (commit `a551c4c5c5df5d26b07111c722cc26ffb2777561`)
**Vendor:** `vendor/rig` now at `v0.41.0`
**Migration guide:** `vendor/rig/MIGRATING.md` covers 0.38→0.41 with before/after code and a symbol reference

## Summary

Major refactor: `rig-core` split into `rig-core` (provider-agnostic contracts) + `rig-agent` (agent runtime). 92 files changed in `rig-core` (−31,956 / +8,189), 31 new files in `rig-agent` (+39,250). Crystal port keeps unified module structure but must align behavior with both crates.

**Key findings from release discussion #2225:** Crate split, one tool path (`Tool::call(&mut ToolContext, Args)`), event-specific provider-independent hooks, `AgentRunner` as only execution path, `PortableTool` contract, WASM target-based (no feature flags), `dynamic_context` restored as hook, `#[rig_tool]` required-ness follows parameter types, embeddings shared transport, MIGRATING.md exists.

### 2.4 Tool system — PortableTool, ToolOutput, simplified dispatch

This is the largest refactor. Upstream collapsed multiple parallel APIs into one.

- [x] **`PortableTool`**: implement context-free tool contract in `src/crig/tool/portable.cr`. On the Crystal side, `Crig::Tool` remains the classic contextual trait; `PortableTool` blanket-implements it.
- [x] **`ToolOutput`**: implement content block types in `src/crig/tool/output.cr`. Strings stay literal text, `JSON::Any` stays JSON, multimodal tools use `ToolResultContent`.
- [x] **Single `call` method**: `Tool::call(&mut ToolContext, Args) -> Result(Output, Error)`. Remove `classify_error`, `call_with_extensions`, `call_structured`.
- [x] **`ToolDyn` → `DynamicTool`**: rename the public erased-tool type.
- [x] **`ToolSet` simplification**: `get_tool_definitions` and `documents` become synchronous and infallible. Registration no longer returns `Result`.
- [x] **Dispatch consolidation**: `ToolSet::execute` and `ToolServerHandle::execute` replace the three-way `call`/`call_with_extensions`/`call_structured` split.
- [x] **Error consolidation**: replace `ToolError`, `ToolFailure`, `ToolReturn`, `ToolOutcome`, `ToolExecutionResult` with `ToolExecutionError`, `ToolErrorKind`, `ToolResult`.
- [x] **`ToolContext`**: replaces both `ToolCallExtensions` and `ToolResultExtensions`. `.tool_extensions(...)` becomes `.tool_context(...)`.
- [x] **Registration names**: `dynamic_tools(sample, index, toolset)` → `retrieved_tools`; `ToolSetBuilder::dynamic_tool(ToolEmbedding)` → `retrieved_tool`.
- [x] Update `src/crig/tool/result.cr` to match upstream `tool/result.rs` changes.
